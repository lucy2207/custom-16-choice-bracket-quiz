Custom Bracket — Pick Your Favorite
====================================

HOW TO USE IT
-------------
1. Double-click index.html to open it in your browser (or right-click
   → Open with → your browser). No install, no server, no internet
   connection needed once the page loads.

2. On the first screen, click the upload area (or drag & drop) and
   pick any 16 images — outfits, food, vacation spots, anything.
   You can remove one by clicking the × on its thumbnail before
   starting.

3. Once you've got exactly 16, "Start the Bracket" lights up. Click
   it, then keep tapping the image you prefer in each match-up.

4. At the end you'll see your champion image plus the path it took
   to get there (what it beat each round).

5. "Play again" reruns the bracket with the SAME 16 images, freshly
   shuffled. "Upload new images" clears everything so you can build
   a whole new quiz from scratch.

GOOD TO KNOW
------------
- Your images never leave your browser — nothing is uploaded to any
  server. They only exist in memory while the tab is open.
- Refreshing the page or closing the tab clears the images, so
  there's nothing to re-upload each time you want a new round of
  quizzing with a new set of pictures.
- To share this with someone else, just send them index.html — they
  open it the same way and upload their own images.
- If you want to host it online (so you can send a link instead of
  a file), you can drag index.html into a static host like Netlify
  Drop, GitHub Pages, or Vercel — no code changes needed.
